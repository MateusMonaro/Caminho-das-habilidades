# 🚀 Caminho-das-Habilidades

💻 Projeto desenvolvido em uma oficina de programação do NAAH/S, com orientação da professora Priscila Ruotolo, utilizando HTML, CSS e JavaScript.

🧠 Criado em comemoração ao mês de conscientização sobre Altas Habilidades e Superdotação (AH/SD).

🎲 O site sorteia desafios de programação para que o usuário desenvolva projetos e coloque em prática sua criatividade, lógica e conhecimentos de programação.
